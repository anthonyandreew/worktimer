# Worktimer

Адаптивное PWA для учёта рабочего времени. Без внешних библиотек, аналитики и сервера.

- Секундомер: старт, пауза, продолжение, сброс с подтверждением.
- Независимый таймер дня: от 1 минуты до 99 часов 59 минут, по умолчанию 8 часов.
- Отсчёт по сохранённым временным отметкам: закрытие вкладки, сон устройства и перезапуск браузера не сбрасывают время.
- Сохранение в localStorage, обновление между вкладками одного браузера, офлайн-режим после первого посещения.
- Установка как PWA, экспорт и импорт резервной копии.

## GitHub Pages

В Settings → Pages → Build and deployment выберите **GitHub Actions**. После push в main workflow `Deploy to GitHub Pages` запустит тесты и опубликует приложение:
https://anthonyandreew.github.io/worktimer/

Вариант без Actions: выберите **Deploy from a branch**, ветку main, папку / (root). Приложение полностью статическое.

## Локально

`npm start` (требуется Python 3), затем http://localhost:8080. Проверки: `npm test` (Node.js 18+).

## Особенности

Данные остаются в текущем браузере. Между устройствами автоматической синхронизации нет. Для переноса можно использовать резервную копию; активные таймеры в ней продолжаются от исходных временных отметок. Очистка данных сайта удалит таймеры. Приватный режим может не сохранять данные после закрытия браузера.

Таймер дня идёт независимо от пауз секундомера. Каждый счётчик можно отдельно поставить на паузу. Изменить длительность дня можно после сброса таймера. Секундомер не останавливается автоматически в конце дня.

Звук завершения работает при открытом активном приложении; браузер и операционная система могут блокировать звук в фоне. В закрытой вкладке сигнал не гарантируется. После открытия приложение покажет актуальное время. Изменение системных часов влияет на расчёт времени.

При изменении офлайн-файлов увеличьте версию CACHE в sw.js.
